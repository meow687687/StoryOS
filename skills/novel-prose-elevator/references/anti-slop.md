# Anti-Slop Rules (binding on every sentence)

Reject and rewrite any output containing:

1. **Em-dash spam** — max 1 em-dash per 300 words. Prefer commas, colons, periods.
2. **`Not X but Y` / `It's not... it's...`** — banned outright. State the thing directly.
3. **Purple triads** — no three-item lyrical lists ("the dust, the dark, the debt"). Max two, and only if the draft had them.
4. **Moralizing endings** — no thesis-s sentences at paragraph/chapter end ("And that was what it meant to..."). End on image or action from the draft.
5. **Uniform rhythm** — no 3+ consecutive sentences within ±4 words of each other. Alternate short (≤8 words), medium, long (25+).
6. **AI adjectives** — ban as decoration unless in draft/bible: `tapestry, mosaic, symphony, dance (of), labyrinth, echo (of), whisper (as verb for non-people), testament, palpable, ineffable, liminal`.
7. **Hollow intensifiers** — ban `very, deeply, truly, utterly, quite literally` unless quoted from draft.
8. **Dialogue sameness** — every speaker keeps their draft's contraction rate, swearing, formality. Never normalize all voices to one register.
9. **Filter-verb pileup** — max 1 per page of `saw/felt/heard/knew/realized/wondered` as main verb.
10. **Symmetry tic** — no mirrored chapter open/close images unless the beats specify a callback.

Self-check before returning: scan output for each item, count violations, fix to zero, and state `Anti-slop: 0 violations` in the change log.
