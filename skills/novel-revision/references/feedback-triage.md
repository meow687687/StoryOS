# Feedback Triage

## Collect

```md
### F3 — beta-A + beta-C — ch02, para 5
- Observation: "I didn't get why Kael trusts the girl so fast" (A); "trust beat felt rushed" (C)
- Class: character (2 readers → weight 2)
```

## Classes

- `confusion` — reader couldn't follow. Usually blocking; check bible/outline gap first.
- `pacing` — bored/rushed. Check beat density (beats per 1k words) before asking.
- `character` — motivation/believability. Route to interrogator-style question.
- `stakes` — "didn't care". Check scene-goal (whose goal, what lost).
- `prose` — line-level. Route to elevator rules; never a revision-pass item alone.
- `taste` — one reader's preference contradicting others or the author's stated intent. Label `SAFE TO IGNORE`, author confirms.

## Rank

1. Multi-reader confusion/character/stakes (blocking likely)
2. Single-reader confusion with a concrete where
3. Pacing clusters
4. Taste (always last, always opt-in)

Contradictory notes on the same where (A: "too fast", B: "too slow") are presented side by side with both quotes — never averaged.
