# Voice Exercise

Give the writer this prompt verbatim (or equivalent neutral prompt if they've already written 300+ words elsewhere — existing material is better than new):

> Write ~300 words: a character you know well waits for someone who is late. They wait somewhere specific. No genre required — a kitchen, a bus stop, anything. Include a little dialogue and one thing the character notices about the place. Messy is fine; your habits matter more than polish.

## Fingerprint extraction

From the sample (or their dumps/drafts), record in `voice.md`:

```md
# Voice: <project>
## Fingerprints
1. Diction: <plain/lyrical/slangy...> — e.g. "..." 
2. Sentence habit: <short punches / long rolls / fragments...> — e.g. "..."
3. Dialogue tic: <contractions always? swearing? formality?> — rate: NN% contractions
4. Formality: <casual/neutral/formal>
5. Signature move: <e.g. ends scenes on action; notices smells first>
## Calibration
- Lesson depth: <new writer (explain terms) / experienced (terse craft notes)>
- Don't-touch list: <quirks to preserve verbatim, e.g. sentence fragments, dialect spelling>
```

Evidence quotes required per fingerprint. The don't-touch list binds the humanizer: those quirks are voice, not errors.
