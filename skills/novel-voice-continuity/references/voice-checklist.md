# Voice Checklist

- [ ] Contraction rate matches author's draft (±10%)
- [ ] No sentence a human wouldn't say aloud on first read (read-aloud test per paragraph)
- [ ] Dialogue speakers distinguishable without tags (diction/formality/tic)
- [ ] 2–3 author word choices per page preserved verbatim (list them)
- [ ] No paragraph starts with the same word 3+ times in a row
- [ ] No word repeated in identical form more than twice per paragraph (except deliberate anaphora in draft)
- [ ] Chapter opens/closes on author's beat, not an invented aphorism
- [ ] Anti-slop re-scan: 0 violations (see novel-prose-elevator/references/anti-slop.md)
